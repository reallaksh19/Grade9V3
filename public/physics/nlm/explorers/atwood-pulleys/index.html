⚡ Governing Model Invariants & String Constraint Pedagogy:
1. String Tension is NOT Weight: For two masses m1 < m2 over an ideal pulley, tension is the harmonic mean: T = 2 m1 m2 g / (m1 + m2). Notice that m1 g < T < m2 g. The heavier mass accelerates downward because m2 g > T; the lighter mass accelerates upward because T > m1 g!
2. Kinematic Inextensibility Invariant: Total rope length L = y1 + y2 + π R = const ⇒ d²y1/dt² + d²y2/dt² = 0 ⇒ a1 = -a2. The bodies share identical acceleration magnitude: a = (m2 - m1) g / (m1 + m2).
3. Movable Pulley Kinematic Ratio: In a movable pulley, pulling the rope by Δy moves the load by only Δy / 2 ⇒ apull = 2 aload. Tension is halved (T = ½ W), doubling the mechanical advantage while doubling the displacement required!

⚖️ The Tension-Weight Asymmetry Proof

Students often guess that string tension is the arithmetic average: (m1 + m2)g / 2. This is physically impossible!

• If T equaled the average weight, the net accelerating force on both bodies would be identical, but their masses are different, violating a1 = a2.
• The Harmonic Mean Invariant: T = 2 m1 m2 g / (m1 + m2). Notice that T is strictly between m1g and m2g.
• When m2 > m1, m2g > T causes body 2 to accelerate downward, while T > m1g pulls body 1 upward with equal acceleration.

⛓️ The Free-Fall Asymptotic Limit

As m1 → 0 (e.g., m1 = 0.1 kg while m2 = 10 kg), the system approaches free fall: a → g. However, tension does NOT approach m2g = 100 N; it vanishes towards T → 2 m1 g ≈ 2 N! The heavy mass drops almost unhindered.

🧠 Targeted Diagnostic Challenges Requires Explorer Invariants

These challenges diagnose and eliminate common multi-body tension fallacies.

Question 1 · The Arithmetic Average Tension Fallacy Diagnostic 2.1
In an ideal Atwood machine with g = 10 m/s², m1 = 2 kg and m2 = 8 kg. What is the tension in the connecting string while the masses are in motion?
Explorer Explanation: The arithmetic average (50 N) is a classic trap! If T were 50 N, then the 2 kg mass would accelerate at (50 - 20)/2 = 15 m/s², while the 8 kg mass would accelerate at (80 - 50)/8 = 3.75 m/s², violating the string length constraint! String inextensibility requires both bodies to have the same acceleration magnitude: a = (8 - 2)/(8 + 2) × 10 = 6 m/s². The tension is T = m1(g + a) = 2(10 + 6) = 32 N (Option C).
Question 2 · The Free-Fall Limiting Boundary Diagnostic 2.2
A 10 kg mass m2 is connected over an ideal pulley to an extremely light 0.1 kg mass m1 (g = 10 m/s²). As m2 accelerates downward, what is the approximate string tension?
Explorer Explanation: When m1 ≪ m2, the system accelerates at almost free-fall: a = (10 - 0.1)/(10.1) × 10 ≈ 9.8 m/s². Because m2 is almost in free fall, its apparent contact resistance is tiny! The tension is T = 2(0.1)(10)(10)/(10.1) ≈ 1.98 N ≈ 2 N. Notice that T is capped by 2 m1 g, NOT by m2 g!
Question 3 · Movable Pulley Kinematic Constraint Diagnostic 2.3
In a 2-segment movable pulley setup supporting a load of weight W, what is the relation between the pulling force F, the string tension T, and the accelerations of the pull hand (apull) and load (aload)?
Explorer Explanation: The two rope segments supporting the movable pulley each carry tension T = F. The upward equilibrium on the pulley is 2T = W ⇒ F = W / 2. However, by the conservation of string length L = 2 yload + ypull = const, differentiating twice gives 2 aload + apull = 0 ⇒ |apull| = 2 |aload|! Work input equals work output: (W/2) × 2d = W × d.

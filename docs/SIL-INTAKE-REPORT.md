# What the parallel tracks' subtopic-intelligence packets can contribute

Generated by `Shared/library/import_sil.py --survey`. It is the substance gate in
`Shared/library/substance.py` applied to each track's own catalogue, judging every
packet against its peers in the same catalogue and nothing else.

The gate reports three things, none of which need to know any subject:

- **DUPLICATED** — the same sentence appears on two packets. One of them is wrong:
  either the text was templated across packets, or the two packets are one packet.
- **TEMPLATED** — the same sentence with each packet's own title substituted in.
  This is what a generator produces, and it defeats a plain duplicate check.
- **SELF_NAMING** — a phrase of three words or fewer containing the name of its own
  declared type: `"Governing relation."` under a RELATION.

Classification labels, shared validity conditions and shared accessibility
requirements are exempt, because repetition there is correct.

## What this is not

It is not a judgement of whether the mathematics or physics in these packets is
correct — the gate never reads for correctness, only for whether two packets say
the same thing. A rejected packet may be perfectly accurate and still be unusable
here, because a library whose purpose is to stop plausible titles concealing
missing reasoning cannot admit text that is identical across thirty-one topics.

Nor is it a claim about those tracks' own gates. Each passes its own six-point
intake check, which counts structural markers — at least four atoms, at least two
misconceptions, the literal string `Flawed Action` appearing twice. None of the six
compares two packets with each other, which is why templated content passes them.

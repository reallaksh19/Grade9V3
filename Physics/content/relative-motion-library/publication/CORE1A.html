Relative velocity in a plane · CORE1A

Relative velocity in a plane

Intrinsic concept difficulty: HARD

Read these before anything that uses them.
Two directions are fixed for the whole bucket: x counts east and y counts north. A number written against x with a minus sign means west, and against y it means south.
A quantity written A/B is A measured from B. The order belongs to the quantity and is not a label attached afterwards.

A number alone does not say where something is.

"Where is it?" has no answer until you say measured from what. Position is a relation, not a property of the object.

What this assumes you can already do:
- Can say where a thing is by pointing or counting paces.

A common wrong idea:
Position is a property the object carries with it.
Tell them apart:
Two people give different answers for where the same chair is. Can both be right?
Instead:
Say what you measured from, then give the number; the number alone is not the answer.
Count paces from the door to the chair: four. Now count from the window to the same chair: four again. Both counts are honest measurements of the same chair, made without moving it, so neither can be dismissed as a mistake. This gives:
door -> chair: 4 paces. window -> chair: 4 paces.
Say each answer in full, out loud: four paces from the door, walking toward the window; four paces from the window, walking toward the door. Adding what each count started from is the only change made, and the two answers stop matching -- so the bare four was hiding the difference rather than describing it. This gives:
"4 paces from the door, toward the window" and "4 paces from the window, toward the door".
Hand someone the number four on its own and ask them to put the chair back where it was. They cannot do it, and what they ask for is exactly what was left out: what the four was counted from. This gives:
"Four from where?" -- the question the listener has to ask back.

Check yourself: Two people are asked where the same chair is. Both answer "four paces". Say whether they have described the same place, and what each would have to add before anyone could tell.
Answer: Not yet decidable: both answers are incomplete in the same way, and each needs what it was counted from.
- Four is a count, and a count on its own does not name a place.
- If both counted from the door they agree; if one counted from the door and one from the window they do not, and the two answers given cannot tell those cases apart.
- What is missing from each is the thing it was counted from, together with which way the paces went.
Verify: Ask someone else to put the chair back using only what was said. If they cannot, the description is still incomplete.

Position measured from the other object.

Replace two positions from an origin by the displacement from B to A.

What this assumes you can already do:
- Signed coordinate-pair arithmetic is available or bridged.

A common wrong idea:
Subtract whichever coordinate appears first in the question.
Tell them apart:
Which displacement carries you from B to A?
Instead:
Draw origin → B → A and reconstruct r_A = r_B + r_A/B before subtracting.
Follow the path origin → B → A. Vector displacements add along consecutive paths. This gives:
r_A = r_B + r_A/B.
Subtract r_B from both sides. Apply the same vector operation to both sides. This gives:
r_A/B = r_A - r_B.

Check yourself: At one instant A is at (7,2) m and B at (3,5) m. Give A relative to B and explain the signs.
Answer: (4,-3) m: 4 m east and 3 m south from B.
- Subtract the same-time coordinates of B from A.
- The negative north component means south.
Verify: Add (4,-3) to B=(3,5); recover A=(7,2).

Checks you can run on your own answer:
- If A and B occupy the same point, r_A/B is zero.
- Reversing A and B reverses the vector.

From relative position to relative velocity.

Subtract two relative-position equations before dividing by a common time interval.

What this assumes you can already do:
- Can construct relative position and interpret displacement over time.

A common wrong idea:
Subtracting the two speeds always gives relative speed.
Tell them apart:
If one object moves east and the other north, do their directions disappear?
Instead:
Compute signed vector components first, then take the magnitude if requested.
Write relative position at t1 and t2. Apply the same relation at both instants. This gives:
r_A/B(t2) - r_A/B(t1) = [r_A(t2)-r_A(t1)] - [r_B(t2)-r_B(t1)].
Group the displacement changes. Vector subtraction distributes through the two same-time equations. This gives:
Delta r_A/B = Delta r_A - Delta r_B.
Divide each term by the same nonzero Delta t. Each quotient is average velocity over that interval. This gives:
vbar_A/B = vbar_A - vbar_B.
For this constant-velocity teaching case, use v for each constant average. No instantaneous calculus limit is needed in this case. This gives:
v_A/B = v_A - v_B.

Check yourself: Why must both displacement changes be divided by the same time interval in this derivation?
Answer: The relation compares how the simultaneous separation changes over one shared interval.
- Write the positions of both objects at t1 and again at t2.
- Subtract those two relative positions.
- Different intervals describe different displacement changes and do not form this comparison.
Verify: For equal constant velocity vectors, the separation must stay constant.

Checks you can run on your own answer:
- If A and B occupy the same point, r_A/B is zero.
- Reversing A and B reverses the vector.
- Equal velocity vectors give zero relative velocity.
- A stationary observer gives v_A/B = v_A.
- Swapping A and B reverses direction.

Check direction, magnitude and observer reversal.

Reconcile the algebraic result with reversal of the observer vector in a geometric construction.

What this assumes you can already do:
- Can subtract velocity components; a magnitude calculation requires a reviewed right-triangle bridge.

A common wrong idea:
A correct length is enough for a correct vector answer.
Tell them apart:
Would the same arrow reversed describe the same observer statement?
Instead:
Name the observer, label both components and inspect the direction before taking a magnitude.
Reverse v_B. Subtraction is addition of the opposite vector. This gives:
-v_B has the same magnitude and opposite direction.
Add v_A and -v_B tail to head. Free vectors may be translated without rotation. This gives:
Resultant v_A/B.
Compare components and reverse the observer order. v_B/A = -(v_A/B). This gives:
Opposite vectors have equal magnitudes.

Check yourself: If v_A/B points southeast, what direction does v_B/A point, and what happens to its magnitude?
Answer: Northwest, with the same magnitude.
- Swap the subtraction order.
- Every component changes sign.
Verify: Adding the two relative vectors gives zero.

Checks you can run on your own answer:
- Equal velocity vectors give zero relative velocity.
- A stationary observer gives v_A/B = v_A.
- Swapping A and B reverses direction.

Question AUTHOR-REL-01

In a common east/north frame, A moves at (6,0) m/s and B at (0,8) m/s. Find the velocity of A relative to B. State its direction and magnitude.

    Conditions:

    1. Constant velocities; common time and parallel nonrotating axes.

    Hints and full answer

    Hints, answers and repair

    Question AUTHOR-REL-01

    Hint 1

    Relative to B means measured from B. Which of the two velocities is the one being subtracted?

    Hint 2

    Subtract axis by axis before doing anything with lengths, and keep both signs; the magnitude is something you compute from the answer, not the answer itself.

    (6,-8) m/s, southeast; magnitude 10 m/s.

    10 m/s

    1. Subtract (0,8) from (6,0).
    2. The southward component is 8 m/s and eastward component 6 m/s.
    3. Using a right triangle, magnitude is sqrt(36+64)=10 m/s.

      Check: Over one second the relative displacement changes by (6,-8) m; reversing the observer gives (-6,8) m/s.

    Relative velocity in a plane: transfer

    Intrinsic concept difficulty: HARD

    Labelled extension, beyond the two-object baseline scope: a swimmer's velocity relative to the water and the water's velocity relative to the ground are both given. Finding the swimmer's velocity relative to the ground needs the same relation used throughout this unit, rearranged: if v_A/C = v_A/B - v_C/B and the current is described as water relative to ground rather than ground relative to water, then v_swimmer/ground = v_swimmer/water + v_water/ground. This is addition, not the subtraction drilled above, and it involves three objects (swimmer, water, ground) instead of two -- decide which relation applies before calculating; do not assume every relative-motion question is a subtraction.

        Question AUTHOR-VEC-03

        Hint 1

        State which vector is being reversed before drawing anything.

        Hint 2

        Translate, do not rotate, the reversed vector.

        Hint 3

        Cross-check the graphical resultant against direct component subtraction.

        P-Q = (6,-8) m/s; magnitude 10 m/s.

        10 m/s

        1. Reverse Q = (0,8) to get -Q = (0,-8) m/s.
        2. Translate -Q to the head of P without rotating it, and add tail-to-head: (6,0)+(0,-8) = (6,-8) m/s.
        3. Cross-check against direct component subtraction: (6-0, 0-8) = (6,-8) m/s -- both routes must agree.
        4. Right-triangle bridge for the magnitude: sqrt(6^2+8^2) = 10 m/s.

          Check: The graphical and component routes produced the same (6,-8) m/s.

          Question AUTHOR-REL-04

          Hint 1

          First decide: does this situation add or subtract the two given velocities? Justify the choice before calculating.

          Hint 2

          Write out which object each velocity is measured relative to before combining them.

          (4,3) m/s; magnitude 5 m/s.

          5 m/s

          1. Identify the relation: swimmer relative to ground = swimmer relative to water + water relative to ground (addition, not subtraction, because the current is already given as water-relative-to-ground).
          2. Add the components: (0,3) + (4,0) = (4,3) m/s.
          3. Right-triangle bridge: magnitude = sqrt(4^2+3^2) = sqrt(25) = 5 m/s.

            Check: If the current were zero, the result would reduce to the swimmer's own (0,3) m/s, as it should.

            Question AUTHOR-REL-05

            Hint 1

            The reversal principle proved for A/B applies to any pair -- it does not need to be re-derived from scratch for M and N.

            (5,-12) m/s; same magnitude (13 m/s) as M relative to N.

            13 m/s

            1. Apply the reversal relation directly to the already-known result: v_N/M = -(v_M/N) = -(-5,12) = (5,-12) m/s.
            2. No need to return to M and N's original velocities -- the reversal principle applies to any relative-velocity result.

              Check: Adding v_M/N and v_N/M gives (0,0) m/s.
